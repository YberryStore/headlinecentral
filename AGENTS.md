# Workspace Rules — Headline Central

## Git & Deployment Policy (Local-Only by Default)
- **Keep Changes Local**: All code edits, builds, and verifications must remain strictly local in the workspace by default.
- **No Automatic Commits or Pushes**: Never run `git commit`, `git push`, or trigger remote deployments automatically after making changes.
- **Explicit Approval Required**: Only stage, commit, or push changes to GitHub when the user explicitly instructs you to do so.
